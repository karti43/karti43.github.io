Go live on GitHub Pages — about 5 minutes

Your GitHub username is karti43, so your free address will be karti43.github.io. Follow these steps in order:

  1. Get your files. Tap Edit site at the top of this page, rearrange and edit anything you like, then tap Download updated index.html. You also need the assets folder with the project cover images — ask Muse for the full site folder if you don’t have it.
  2. Create the repo. On github.com, click New repository, name it exactly karti43.github.io, set it to Public, and create it.
  3. Upload the files. In the new repo choose uploading an existing file, add index.html and the whole assets folder, then commit the changes.
  4. Turn on Pages. Open the repo’s Settings → Pages, set the source to Deploy from a branch, pick main and / (root), and save.
  5. You’re live. Within a minute or two your portfolio is public at https://karti43.github.io. Every time you upload a newer index.html, the live site updates itself.

Want your own domain name later (like karthikkannekanti.com)? Buy it at Cloudflare, then add it under the same Settings → Pages screen — HTTPS stays free.
